# 💎 Ruby Brasil

> Plataforma web de catálogo e atendimento desenvolvida com Next.js, Prisma ORM e PostgreSQL.

Disponível em: [https://rubybr.com.br](https://rubybr.com.br)

---

## ⚡ Sobre o Projeto

O **Ruby Brasil** é uma aplicação moderna voltada para a exibição de catálogo de produtos e conversão direta via atendimento integrado. Construído com foco em velocidade, design responsivo e arquitetura limpa.

### 🤖 Construído 100% com Antigravity

Este projeto foi **totalmente idealizado, estruturado e codificado utilizando a IDE Antigravity**, explorando fluxos avançados de engenharia de software acelerada por agentes de IA:

* **Arquitetura & Scaffold:** Definição completa da base Next.js com App Router e modelos do Prisma orientados por agentes.
* **Componentização Inteligente:** Criação de componentes desacoplados, responsivos e estilizados via Tailwind CSS.
* **Resolução de Problemas & CI/CD:** Suporte contextual para migração de banco de dados e configuração de pipeline de deploy para a Vercel.

---

## 🛠️ Tecnologias

* **Framework:** [Next.js](https://nextjs.org/) (App Router, React)
* **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
* **ORM:** [Prisma ORM](https://www.prisma.io/)
* **Banco de Dados:** PostgreSQL (Serverless via Neon)
* **Deploy & Domínio:** [Vercel](https://vercel.com/) / GoDaddy
* **IDE & Agent Workspace:** [Antigravity](https://antigravity.google/)
